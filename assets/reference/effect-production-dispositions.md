# Remaining live feedback — per-effect production review

2026-09-19 reconciliation under accepted D-192. Approved cards and stills remain
appearance references; this brief schedules the remaining live cue choices when
their models/effects are produced. It does not mark those choices selected or
authorize new gameplay. No duplicate standalone still is presently justified for
the cases below: onset, opportunity, completion and expiry must be compared in use.

Each row triggers a bounded preview brief before implementation: cite exact selected
images and authored balance, identify cameras/backgrounds and failure cases, allow
two implementation/capture/review cycles with a finite active-time budget, then
record the outcome. Use both independent visual screens, lead inspection and human
artistic selection. If a preview exposes a distinct silhouette/color/appearance
ambiguity that needs artwork, generate that specific reference before proceeding.
Do not infer physical values from paintings or hide required cues in bloom.
