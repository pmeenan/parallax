## Accepted sequencing decision — D-195

D-187's output profiles still request additional static angle/construction/state
coverage before production. Many selected targets honestly retain those gaps;
zero Missing catalog rows does not satisfy every profile. D-192 covers motion,
D-193 courtyard views, and D-194 shore lighting only. In particular, DIR-002's
original lane does not have an approved exact gloomy counterpart merely because
the later courtyard light pair is approved.

**Recommended:** accept this selected collection as the concept-direction baseline
and move remaining supplementary static profiles into each subject's production
brief. This includes unshown kit sides/joints, precise fits, material light/wetness/
grazing/scale comparisons, character expressions/fits/light states, environment
connections and remaining UI states. It changes when the required review happens,
not its quality criteria. The human explicitly selected this sequence2026-09-20.

Before each asset/scene/UI package, enumerate that target's remaining profile views
and decisions, cite selected references, and produce the missing evidence alongside
the model or implementation. Both independent screens and human artistic approval
remain required before accepting the visual result. If an unselected appearance or
design ambiguity needs concept art, generate that bounded reference first. No blanket
approval of unseen detail, no silent style reinterpretation and no library admission
without QA/rights. Deferred features are not promoted into implementation scope.

The alternative is to retain the full current prerequisite and commission the
remaining static profiles before any paving production. This review recommends the
per-subject production sequence because most residuals concern shared geometry,
materials and usable states that isolated paintings have not reliably preserved.
