# Cycle 1 — geometry only

Authored afresh in native Blender 5.2.1 LTS through the live MCP connection. The
initial live file was verified unsaved, clean, with only the default Cube, Camera
and Light. A separate scene holds all new work; the retained source saves that scene
only. No former paving generator or shader was reused. Selected references were
actually viewed before authoring: 104 stone family v4, 108 limestone v1, 103 assembly.

The first construction invocation stalled while reading each vertex normal after
mutating geometry. That invalidated Blender's normal cache repeatedly. Root stopped
the verified clean/default process and reopened the same executable. The retained
script snapshots normals before editing coordinates. Corrected construction then
completed in about 3.7 seconds; no artistic render existed before this technical fix.
This remains the first artistic capture cycle, not a new allowance.

The support plane is placed at the measured minimum stone Z, 1.952 mm. It is a plain
neutral support, not a claim about authored soil contact. Gray material has no image,
noise, normal or bump nodes. All relief in the captures is geometry. Metrics are source
checks only; 823,956 triangles deliberately retain high-resolution authoring detail
and do not meet or claim runtime LOD admission.

Preliminary author inspection of oblique/reverse is **fail**: basic mass and calm top
are established, but outer faces are too clean and polygonal, edge bites too isolated
and stamp-like, and illumination too bright to inspect the intended gray form well.
Both independent reviews and root adjudication are required before cycle 2.
